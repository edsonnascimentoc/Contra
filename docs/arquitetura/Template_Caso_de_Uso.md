# Template de Caso de Uso 

**Nome do Caso de Uso:** Ex: Cadastro de Eixos Tecnológicos 

**Descrição Sucinta:** Breve resumo do objetivo do caso de uso. 

**Atores:** Ex: Administrador do sistema 

**Pré-condições:** O que deve estar garantido antes do início do caso de uso. 

**Fluxo Básico:** Passo a passo do cenário principal. 

**Fluxos Alternativos:** Desvios, exceções e variações do fluxo principal. 

**Estrutura de Dados:** Lista dos dados manipulados, criados ou alterados, com breve descrição de cada campo. 

**Regras de Negócio:** Regras específicas que impactam o caso de uso (podem ser referenciadas por código, como RN1, RN2). 

**Pós-condições:** O que deve estar garantido após a execução do caso de uso.
